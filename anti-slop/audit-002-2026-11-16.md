# antislop audit 002 (2026-11-16)

Scope: File Explorer, the two areas marked in red: the top-right control group and the pane header row (path, node selector, refresh).
Source: `lib/widgets/file_explorer_view.dart` (`build` header band, `_buildPaneHeader`).
Mode: AFTER (audit only, nothing modified until numbers are approved).

Design Read: file manager for people moving files between local and SSH hosts, dark tool UI, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

## Findings

| # | Priority | Rule | Finding | Fix |
|---|----------|------|---------|-----|
| 1 | HIGH | R-39 | Refresh `IconButton` has no tooltip or label, so it has no accessible name. The three header icon buttons use a tooltip only, which is fine. The path `InkWell` has no semantic label either. | Add `tooltip: 'Refresh [F5]'` and `Semantics(label: 'Current path, activate to change')` on the path. |
| 2 | HIGH | R-39 | Dual-pane toggle shows its on/off state by color alone (cyan vs grey). | Show state with shape too: filled background chip when on, plain when off, plus `isSelected`. |
| 3 | MEDIUM | R-01, R-29 | Three adjacent icons carry three different colors (cyan, cyan, green) with no meaning. Help is green and settings is cyan for no stated reason. The pane header adds two more hues (green/blue node border). The accent is spread, not placed at one key moment. | One neutral icon color. Accent reserved for the single active state (active pane, toggle on). |
| 4 | MEDIUM | R-12, core Part 3 (focal point) | The active pane's path bar is a solid cyan block with black bold text. It is the heaviest element on the screen and outweighs the file list the user is working in. A whole filled bar just to say "this pane is active". | Same surface for both panes. Mark active with a 2px accent line under the path bar and brighter text. |
| 5 | MEDIUM | R-14 (variation without reason) | Path, node selector, and refresh are three unrelated treatments in one row: filled bar, outlined pill, bare icon. They read as three separate components for one control group. | One control family: shared height, shared border treatment, node selector as a quiet dropdown chip, refresh as an icon button of the same height. |
| 6 | LOW | C-3, R-31 | The "Remote & Local File Explorer" band repeats the "FILE EXPLORER" tab title. A code comment says it exists "to satisfy test". A section kept for a test is not content-driven. | Remove the band, move the three controls into the pane-level toolbar or the status bar row, and update the test to assert on real UI. |
| 7 | LOW | R-31, C-1 | The path is plain text that opens a modal to type an absolute path. No breadcrumb, so the most common navigation (go up two folders) needs typing. | Breadcrumb segments that are each clickable, with edit-on-click for the full path. Optional, functional change. |

## Not flagged

- Contrast of the path text: black on `#56B6C2` and `#ABB2BF` on `#2C313C` both pass 4.5:1. The hint text at `#5C6370` in the filter bar is out of scope here and should be checked separately.
- Radius 2 is consistent across the row, so R-11 does not apply.
