# antislop audit 003 (2026-11-16)

Scope: every dialog the File Explorer opens, plus the shared dialog parts.
Sources: `lib/widgets/file_explorer_dialogs.dart` and its parts (`_progress`, `_node_picker`, `_message_dialogs`, `_file_dialogs`, `_settings`, `_help`), the call sites in `file_explorer_view.dart`, and `draggable_dialog.dart`.
Mode: AFTER (audit only, nothing modified until numbers are approved).

Design Read: file manager for people moving files between local and SSH hosts, dark terminal-style tool UI, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

Dialogs covered:

| Dialog | Class | Opened from |
|---|---|---|
| Change directory | `FileExplorerPromptDialog` (title CHANGE DIRECTORY) | `_promptChangeDirectory` |
| Create file/folder, rename, merge | `FileExplorerPromptDialog` | view |
| Select browse target (node) | `FileExplorerNodePickerDialog` + credentials + custom SSH `AlertDialog`s | `_pickNode` |
| Confirm (copy, move, delete, move-to-folder) | `FileExplorerConfirmDialog` | view |
| Drop action (copy or move) | `FileExplorerDropActionDialog` | view |
| Notification | `FileExplorerNotificationDialog` | view |
| Open with | `FileExplorerOpenWithDialog` | view |
| View/edit file | `FileExplorerViewFileDialog` | view |
| Appearance settings | `FileExplorerSettingsDialog` | view |
| Help (shortcuts) | `FileExplorerHelpDialog` | view |
| Transfer progress | `FileExplorerProgressDialog` | **nowhere (see #4)** |

Contrast numbers below were computed with `contrast-check.py`, not estimated.

| 1 | HIGH | R-25 | `#5C6370` is the muted text color in every dialog: hint lines, `message2`/`Target:` path, node subtitles (`Host: ... \| User: ...`), footer key hints, `Cancel` text buttons, close icons, progress detail line. | 2 | HIGH | R-32 | The settings dialog cannot be operated by keyboard. ## Not flagged

- Delete confirmation: red border, `defaultYes: false`, permanent-action warning. This is a good use of semantic color.
- No em dashes in any dialog file (R-02 PASS by grep).
- `Esc` closes confirm, drop action, notification, open with, help, and the node picker (via its search field). Prompt, view file and the `AlertDialog`s rely on the framework default dismiss; they were not run, so treat their `Esc` as unverified.
- Contrast that passes: `#56B6C2` on `#1E222B` 6.72:1, `#E06C75` 4.98:1, `#98C379` 7.90:1, `#E5C07B` 9.22:1, black on `#98C379` 10.42:1, `#61AFEF` on selected `#2B3A4A` 4.92:1.
- Shadow and radius: one shadow and radius 4 across the shell, consistent (R-11, R-12 do not apply). Dark theme is justified for a terminal tool (R-21).
- `floating_send_progress_dialog.dart` belongs to the Nexus screen, not the File Explorer, so it is out of scope here.

## Not verified

The audit is by code reading. The app was not run, so focus order, `Esc` on the framework-default dialogs, and the real rendering of the colors were not exercised (R-35 applies once fixes are made).
