## Notes and deviations from the audit

1. Audit #10 said to build the shell from `AppTheme` tokens. I did not: `AppTheme` is a different palette (blue accent, `#16181F` surface) and the explorer panes use the One Dark values, so switching would have made the dialogs look foreign to the pane under them. The values now live in one place (`_Dlg`) instead.
2. Custom SSH keeps the default underline field style (no outline box). Only the credentials dialog and prompt were given an explicit 3:1 boundary. If you want the same outlined boxes on every field, say so.
3. Node picker list rows still use the `#2C313C` row border for unselected rows (selection is by accent border and fill, the row text carries the affordance). Not changed.
4. The settings preview box keeps its own yellow/green sample colors on purpose: it mimics the pane file list.
